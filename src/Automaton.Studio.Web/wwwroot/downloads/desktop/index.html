🔧 Installation Options

Option 1: Installer (Recommended)

  1. Download the appropriate installer for your architecture
  2. Right-click and "Run as administrator"
  3. Follow the installation wizard
  4. Launch from Desktop shortcut or Start Menu

Option 2: Portable

  1. Download the ZIP file for your architecture
  2. Extract to your preferred location (e.g., C:\Tools\AutomatonStudio)
  3. Run Automaton.Studio.Desktop.exe from the extracted folder

Option 3: PowerShell Script

For automated installations or custom configurations:

# Basic installation iwr -useb https://studio.automaton.monster/downloads/install-desktop.ps1 | iex # Portable installation to custom directory .\install-desktop.ps1 -InstallPath "C:\Tools\AutomatonStudio" -Portable # Installation without desktop shortcut .\install-desktop.ps1 -CreateDesktopShortcut:$false
