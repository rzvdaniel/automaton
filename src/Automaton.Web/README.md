# Automaton Presentation Website

A modern, tech-focused presentation website for the Automaton automation platform.

## Overview

This website serves as the main marketing and information site for Automaton, designed to showcase the platform's capabilities and drive users to the main application at `studio.automaton.monster`.

## Design Philosophy

The website uses a **tech-focused design** that emphasizes:
- **Coding aesthetics** - Code editor mockups, syntax highlighting
- **Workflow visualization** - Diagram elements, flow charts
- **Modern dark theme** - Professional appearance for developers
- **AI and automation themes** - Highlighting the AI-powered capabilities

## Key Features

### Visual Elements
- **Hero section** with interactive code editor mockup and workflow diagram
- **Feature cards** showcasing platform capabilities
- **Documentation preview** with interactive tabs
- **High-quality Unsplash images** for professional appearance

### Technical Stack
- **Pure HTML/CSS/JavaScript** - No frameworks, fast loading
- **Modern CSS features** - Grid, Flexbox, CSS variables, animations
- **Responsive design** - Mobile-first approach
- **Accessibility** - Proper focus states, semantic HTML
- **Performance optimized** - Minimal dependencies, optimized images

### Key Sections

1. **Hero Section**
   - Compelling headline with AI emphasis
   - Visual code editor and workflow diagram
   - Clear CTAs to studio.automaton.monster
   - Key statistics and value propositions

2. **Features Section**
   - AI Workflow Generation
   - Visual Flow Designer
   - Flexible Deployment
   - Python Integration
   - Real-time Monitoring
   - Advanced Scheduling

3. **Use Cases Section**
   - E-commerce Automation

   - DevOps Integration

4. **Documentation Section**
   - Links to https://studio.automaton.monster/docs

   - Strong conversion focus
