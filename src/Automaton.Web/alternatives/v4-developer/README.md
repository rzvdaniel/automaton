# Version 4: Developer/Coding Focus

## Theme
VS Code-inspired dark theme designed for developers and technical audiences.

## Key Features
- **Dark Background**: `#1E1E1E` matching VS Code
- **Monospace Font**: JetBrains Mono throughout
- **Code Syntax Highlighting**: Realistic color scheme
- **Terminal Aesthetics**: Code blocks styled as terminal windows
- **Developer Terminology**: Uses terms like `$`, functions, methods

## Color Palette
- Background: `#1E1E1E`
- Surface: `#252526`
- Accent Blue: `#007ACC`
- Accent Green: `#4EC9B0`
- Keywords: `#569CD6`
- Strings: `#CE9178`
- Comments: `#6A9955`

## Target Audience
- Developers
- DevOps engineers
- Technical decision makers
- GitHub/GitLab users
- Command-line enthusiasts

## Content Approach
- Code examples front and center
- Terminal-style navigation (`$ command`)
- Bracket notation for links `[home]`
- Function-style feature names `visual_designer()`
- Realistic workflow code samples

## Best Used For
- Developer conferences
- Technical blog posts
- GitHub repository README
- Developer-focused marketing
