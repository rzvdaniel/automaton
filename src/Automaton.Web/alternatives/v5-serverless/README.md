# v5-serverless - Cloud Native Serverless Theme

## Overview
This version emphasizes Automaton's serverless architecture and cloud-native capabilities. It's designed to appeal to cloud architects, DevOps teams, and organizations looking to eliminate infrastructure management.

## Design Approach
- **Color Scheme**: Sky blues and purples (#667EEA, #764BA2) representing cloud/sky
- **Visual Elements**: Animated floating clouds, lambda (λ) icon for serverless
- **Typography**: Poppins (modern, friendly, approachable)
- **Imagery**: 8+ Unsplash photos of cloud computing, data centers, distributed systems

## Key Features
- Comparison table: Traditional vs Serverless
- Emphasis on "zero servers to manage"
- Pay-per-use cost model highlighted
- Elastic scaling benefits
- Real Unsplash imagery for credibility

## Target Audience
- Cloud architects
- DevOps/Platform engineers
- CTOs looking to reduce infrastructure costs
- Teams migrating to cloud-native architectures

## Content Focus
- Serverless benefits (cost, scalability, maintenance)
- Event-driven workflows
- Pay-per-execution pricing
- Zero infrastructure management

## Technical Details
- Pure CSS animations (floating clouds)
- Gradient backgrounds
- Responsive grid layouts
- Image-heavy design with real cloud/tech photos

## Use Case
Perfect for marketing to modern engineering teams who prioritize cloud-native solutions and want to eliminate server management overhead.
