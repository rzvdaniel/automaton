# Version 9: Startup/Y-Combinator Style

## Theme
Bold, conversion-focused design inspired by successful YC startups.

## Key Features
- **Orange Accent**: `#FF6600` (YC orange)
- **High Contrast**: Black text on white background
- **Bold Headlines**: Large, attention-grabbing typography
- **Social Proof**: Traction metrics prominently displayed
- **Problem/Solution**: Clear value proposition
- **Single CTA**: Focus on one primary action

## Color Palette
- Primary: `#FF6600` (YC Orange)
- Background: `#FFFFFF`
- Text: `#000000`
- Gray: `#F6F6F6`

## Target Audience
- Startup founders
- Product Hunt users
- Hacker News readers
- Early adopters
- Investors

## Content Approach
- **Problem-first**: Clearly state the pain
- **Simple solution**: One sentence per benefit
- **Comparison table**: Traditional vs Automaton
- **Social proof**: User count, testimonial
- **Urgency**: "Start today", "2 min setup"
- **No fluff**: Direct, concise copy

## Conversion Elements
- "Used by 1,000+ teams" badge
- Large CTA buttons
- "No credit card required" messaging
- Comparison with traditional approach
- Customer testimonial
- Multiple CTAs throughout

## Best Used For
- Product Hunt launch
- Hacker News submission
- Startup pitch decks
- Investor presentations
- Landing page A/B testing
