# Automaton CLI

Automaton CLI is the .NET global tool for creating, validating, deploying, and publishing Automaton apps.

## Install

```bash
dotnet tool install --global Automaton.Cli
```

## Common commands

```bash
automaton login
automaton create my-app
automaton validate
automaton deploy
automaton publish
automaton --version
```
