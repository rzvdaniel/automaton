# Platform Pages

This guide provides an overview of the Automaton platform interface and what you can accomplish on each page.

## Main Navigation

### Dashboard (Home)
The main landing page provides an overview of your automation environment:
- **Quick Stats**: Summary of your flows, runners, and recent activity
- **Recent Flows**: Recently created or executed automation workflows
- **Runner Status**: Overview of connected runners and their current status
- **Quick Actions**: Shortcuts to create new flows or access key features

### Flows
The central hub for managing your automation workflows:
- **Flow List**: View all your automation flows with status indicators
- **Create Flow**: Start building new automation workflows
- **Flow Search**: Find specific flows by name or content
- **Flow Management**: Organize flows with favorites and tags

#### Flow Designer (`/flow/designer/{flowid}/{flowname}`)
Visual editor for building and modifying automation flows:
- **Canvas**: Drag-and-drop interface for designing workflows
- **Toolbox**: Available steps and components to add to your flow
- **Properties Panel**: Configure settings for selected steps
- **Connections**: Define execution paths between steps

#### Flow Logs (`/flow/logs/{flowid}/{flowname}`)
Monitor and troubleshoot flow execution:
- **Execution Logs**: Detailed logs of flow runs
- **Error Messages**: Information about failures and issues
- **Performance Metrics**: Execution times and resource usage
- **Log Filtering**: Search and filter logs by date, status, or content

#### Flow Activity (`/flow/activity/{flowid}/{flowname}`)
Track flow execution history and performance:
- **Execution History**: Complete record of flow runs
- **Success/Failure Rates**: Statistics on flow reliability
- **Performance Trends**: Track execution times over time
- **Activity Timeline**: Visual timeline of flow executions

#### Flow Schedule (`/flow/schedule/{flowid}/{flowname}`)
Automate flow execution with scheduling:
- **Schedule Configuration**: Set up recurring or one-time executions
- **Schedule Types**: Choose from various scheduling patterns
- **Schedule Status**: Monitor active and paused schedules
- **Schedule History**: Review past scheduled executions

#### Flow Settings (`/flow/settings/{flowid}/{flowname}`)
Configure flow-specific options:
- **Basic Settings**: Flow name, description, and tags
- **Execution Settings**: Runner selection and timeout configurations
- **Variable Settings**: Default values and flow-level variables
- **Permissions**: Access control for flow sharing

### Runners
Manage the execution agents that run your automation flows:
- **Runner List**: View all connected runners with status indicators
- **Runner Details**: Monitor individual runner health and activity
- **Connection Status**: Track online/offline status of runners
- **Runner Management**: Configure runner settings and capabilities

### API Keys
Manage authentication for runners and external integrations:
- **Key Management**: Create, view, and revoke API keys
- **Key Types**: Different access levels (runner, execute, readonly)
- **Key Permissions**: Configure what each key can access
- **Usage Monitoring**: Track API key usage and activity

### Downloads Hub
Access Automaton applications and resources:

#### Downloads (`/downloads`)
Download runner applications for different platforms:
- **Platform Selection**: Choose Windows, macOS, or Linux versions
- **Version History**: Access different runner versions
- **Installation Instructions**: Platform-specific setup guides
- **Requirements**: System requirements and prerequisites

#### Desktop (`/desktop`)
Download the Automaton Desktop application:
- **Desktop Download**: Get the native Windows application
- **Installation Guide**: Step-by-step installation instructions
- **System Requirements**: Hardware and software requirements
- **Release Notes**: Information about features and updates

### Settings
Configure your account and platform preferences:
- **Account Settings**: Update profile information and preferences
- **Platform Configuration**: Customize interface and behavior
- **Security Settings**: Manage passwords and authentication
- **Notification Preferences**: Configure alerts and notifications

### Onboarding
Get started guide for new users:
- **Welcome Tour**: Introduction to the platform features
- **Sample Flows**: Pre-built flows to help you learn
- **Getting Started Checklist**: Step-by-step setup process
- **Tutorial Videos**: Visual guides for key features

### Account
Manage your user account details:
- **Profile Information**: Update name, email, and contact details
- **Account Status**: View subscription and usage information
- **Billing Information**: Manage payment methods and invoices
- **Account Security**: Password changes and security settings

## Quick Actions

### Global Actions
Available from most pages:
- **Create New Flow**: Start building a new automation
- **View All Runners**: Check runner status quickly
- **Access Downloads**: Get desktop or runner applications
- **Account Menu**: Access settings and logout options

### Page-Specific Actions
Each page offers relevant quick actions in the interface:
- **Flow pages**: Run, edit, schedule, or duplicate flows
- **Runner pages**: Connect new runners or check status
- **API Keys**: Generate new keys or check permissions

This structure provides a comprehensive yet streamlined experience for managing your automation workflows and platform resources.
