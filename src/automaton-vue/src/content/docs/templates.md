# Workflow: Templates

Use templates when you want a working starting point instead of a blank project.

## Best for

- Learning by example
- Forking a known-good structure
- Faster onboarding for new users

## Flow

1. Open the Apps area.
2. Go to the **Templates** tab.
3. Pick a template.
4. Fork it into your own apps.
5. Continue in the App Editor or your local repo.

## Recommendation

Templates are a strong onboarding path because they show the expected project layout and controller patterns in a concrete example.
