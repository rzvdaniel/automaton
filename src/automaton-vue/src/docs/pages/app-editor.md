# App Editor

Use the App Editor when you want the fastest browser-first workflow.

## Best for

- quick prototypes
- trying ideas without local setup
- editing in the browser

## Simple flow

1. Add an AI provider key in **Settings → AI Keys**
2. Create a new app
3. Describe what you want
4. Review the generated files
5. Click **Deploy Backend** when backend code changes
6. Click **Publish** when you want a public URL

## Example prompt

```text
Build a poker planning app where users vote on story complexity.
```

## When to switch to the CLI workflow

- you want Git history
- you want to work in Cursor or VS Code
- the app is growing beyond a small prototype
- you want the AI to work directly in your local repo

At that point, export the app or pull it locally and continue with the CLI workflow.
