# Common Workflows

## Create a new hosted-runner tier

1. Create the technical specification.
2. Create or edit the subscription plan.
3. Enable the Hosted Runner capability.
4. Select the active specification.
5. Set visibility.
6. Save and assign the plan to test users.
7. Provision or reprovision a test runner and verify its snapshot and endpoint.

## Add a new runner host

1. Prepare the server and required directories.
2. Install the Infrastructure Runner.
3. Complete enrollment.
4. Validate the host.
5. Approve it if required.
6. Enable scheduling.
7. Confirm that reported health and available capacity are correct.

## Move a plan to a larger runner

1. Assign the new specification to the plan.
2. Existing containers remain on their current contract and placement.
3. Explicitly reprovision affected containers when ready.
4. Verify the new active snapshot, host assignment, runtime endpoint, and deployment status.
