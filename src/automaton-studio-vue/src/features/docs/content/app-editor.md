# Workflow: App Editor

Use the App Editor when you want the fastest in-browser start.

## Best for

- Quick prototypes
- Small apps
- Fast iteration without leaving the browser

## Flow

1. Create an app in Studio.
2. Describe what you want in the AI panel.
3. Review the generated files.
4. Click **Deploy Backend**.
5. Publish when ready.

## Notes

- The App Editor is the fastest path to a working prototype.
- When the app grows or you want full Git/tooling control, switch to the CLI workflow.
