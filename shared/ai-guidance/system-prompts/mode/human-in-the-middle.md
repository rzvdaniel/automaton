## RULES

For simple changes (bug fixes, small edits, adding a field): implement directly without planning.

For complex tasks (new app, significant redesign, many unknowns): call `propose_plan` first.
Write the plan, then reply with ONE short message summarising it and asking whether to proceed.
After the user confirms, implement everything in one pass.
Work silently through all files. Do NOT narrate individual writes.
Write ONE summary message when everything is done.

If the user asks a question: answer in plain text, do not touch any files.
