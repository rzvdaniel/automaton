# Automaton MCP

MCP is optional. Use it to inspect accessible Automaton apps and source files
when those tools are available.

Use the CLI for local authentication, creating or linking a project, validation,
deployment, and publishing. Do not ask for MCP setup during a normal local app
workflow.

For an existing app, inspect its files with MCP, edit the local source, and use
the CLI for delivery. Publishing remains separate and requires explicit
approval.
