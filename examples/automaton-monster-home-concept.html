The product promise should fit in three steps.

The homepage should teach the user the setup path, then stop over-instructing. The generated local guidance should carry the agent details.

1

Install the CLI

One global tool gives the AI a stable execution path instead of asking it to guess how Automaton works.

2

Run setup once

Setup handles auth, creates AGENTS.md, writes .automaton instructions, and gives the current folder enough context.

3

Ask for the app

The human prompt becomes simple: describe the product. The agent reads the local instructions and uses the CLI.
