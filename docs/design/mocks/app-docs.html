Server Keeper

Live stats, alerts and one-click maintenance for this server. It was called Server Console, and it replaces Watchtower: the backup warnings Watchtower sent are here now. It needs an Automaton server: it reads the server's own health, backups and apps.

  • Layout: three tabs. Overview, Maintenance and Apps on this machine.
  • Home card: Studio Home shows a card with the status, disk use, how old the last backup is, the Automaton version and the active alerts.
  • fail2ban line: with security:read approved, the Home card shows "fail2ban: on · N banned in 24 h".

Install and set up

  1. Install it from Apps → Catalog.
  2. Fill in the settings and secrets below and deploy.
  3. An administrator approves the permissions in Admin → Apps → Permissions.
NameKindMeaning
EMAIL_TOsettingWho gets warning emails: administrators (default), owner, project or off.
WEBHOOK_URLsecretOptional: a Slack, Discord or Telegram webhook.
DISK_FREE_WARN_PERCENTsettingDefault 20 (warn when the disk is more than 80% full).
