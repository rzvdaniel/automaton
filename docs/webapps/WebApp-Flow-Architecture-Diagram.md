?SECURITY LAYERS     ?
???????????????????????????????????????????????????????????????????????????

Layer 1: Request Origin Validation
  ? Only accepts requests with X-WebApp-Slug header
  ? Validates request comes from /web/* route

Layer 2: Web App Validation
  ? Verifies web app exists in database
  ? Confirms web app is published
  ? Checks web app has associated owner

Layer 3: API Key Authentication
  ? Retrieves owner's WebApp-scoped API key
  ? Validates API key is active
  ? Checks API key not expired
  ? Verifies correct scope (WebApp)

Layer 4: Permission Check
  ? Uses owner's permissions for flow access
  ? Uses owner's runners for execution
  ? Respects owner's resource limits

Layer 5: Audit Logging
  ? Logs full execution chain
  ? Tracks anonymous user ? app ? owner
  ? Records all parameters and results

## Key Takeaways

1. **Client sends app slug** (`X-WebApp-Slug` header) ? Server identifies context
2. **Server finds app owner** ? No client-side user tracking needed
3. **Server retrieves owner's API key** ? Secure server-side authentication
4. **Flow executes with owner's permissions** ? Full accountability
5. **Complete audit trail** ? Anonymous user ? app ? owner ? execution

**Security:**  
?? **Zero API keys in browser**  
?? **All authentication server-side**  
?? **Owner accountability enforced**  
?? **Comprehensive logging**

**Simplicity:**
? **One WebApp API key per owner**  
? **Automatic for all owner's apps**  
? **No client-side auth code**  
? **Transparent to end users**
